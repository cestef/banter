# banter-macros

Procedural macros for [banter](https://crates.io/crates/banter): `#[commands]` builds a
command table from an `impl` block, `#[derive(FromArg)]` parses unit enums by name.

Use them through `banter`, which re-exports both with its default `macros` feature.
